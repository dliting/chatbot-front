## 1. 产品概述

### 1.1 产品定位
基于 Vue 3 + Element Plus 开发的可嵌入 AI 聊天机器人前端组件，支持悬浮球/侧边栏形态、响应式布局、多模态交互。

### 1.2 目标用户
- 需要在网站中集成 AI 对话功能的开发者
- 需要可定制化 Chatbot UI 的产品团队
- Vue 3 项目开发者（组件化嵌入）
- 非 Vue 项目开发者（iframe 嵌入）

### 1.3 核心价值
1. **开箱即用**: 无需复杂配置即可集成到现有项目
2. **响应式设计**: 自适配 PC/移动端不同屏幕尺寸
3. **多模态交互**: 支持文本、图片等多种输入方式
4. **灵活嵌入**: 支持 Vue 组件和 iframe 两种嵌入方式
5. **样式隔离**: 不污染宿主页面样式

## 2. 功能需求

### 2.1 核心功能 (Must Have)

#### 2.1.1 文本交互
| 需求ID | 需求描述 | 验收标准 |
|--------|----------|----------|
| F-001 | 用户输入文本并发送 | 输入框支持多行文本，发送后消息显示在聊天区域 |
| F-002 | AI 流式输出回答 | 消息以打字机效果逐字显示，支持滚动到底部 |
| F-003 | 区分用户/AI 消息气泡 | 用户消息右对齐，AI消息左对齐，样式有明显区分 |
| F-004 | 发送状态提示 | 发送中显示加载状态，发送失败显示错误提示 |

#### 2.1.2 悬浮球与面板展示
| 需求ID | 需求描述 | 验收标准 |
|--------|----------|----------|
| F-005 | 悬浮球初始显示 | 默认显示在页面右下角，可通过配置调整位置 |
| F-006 | 悬浮球自定义图标 | 支持自定义图标，默认为聊天气泡图标 |
| F-007 | 悬浮球可拖拽 | 拖拽过程中跟随鼠标移动，释放后固定位置 |
| F-008 | 展开/收起面板 | 点击悬浮球展开聊天面板，点击关闭按钮收起 |

#### 2.2.2.1 悬浮模式特性 ####
- 继承 DraggableWindow 的所有能力
- 8方向调整大小
- 拖动标题栏移动
- 圆角矩形样式
- 悬浮窗口位置和大小记忆

#### 2.1.3 响应式布局
| 需求ID | 需求描述 | 验收标准 |
|--------|----------|----------|
| F-009 | PC 端侧边栏模式 | 面板固定在侧边，宽度可配置 (380-600px) |
| F-010 | 移动端全屏模式 | 屏幕宽度 < 768px 时自动全屏显示 |
| F-011 | 内容自适应 | 所有元素随面板宽度自适应，无内容溢出 |

## 3. 非功能需求

### 3.1 性能要求
| 指标 | 要求 |
|------|------|
| 首次加载时间 | < 300ms (无大量历史消息) |
| 打包后体积 | < 500KB (gzip 压缩后) |
| 长列表渲染 | 使用虚拟滚动，支持 1000+ 消息流畅显示 |
| 拖拽响应 | 拖拽事件节流处理 (100ms 间隔) |

### 3.2 兼容性要求
| 类型 | 支持范围 |
|------|----------|
| 浏览器 | Chrome >= 88, Firefox >= 85, Safari >= 14, Edge >= 88 |
| Vue 版本 | Vue 3.x |
| 移动端 | iOS Safari >= 14, Android Chrome >= 88 |

### 3.3 安全要求
| 要求 | 说明 |
|------|------|
| XSS 防护 | 用户输入内容需转义处理 |
| 样式隔离 | CSS Scoped + BEM 命名，避免样式污染 |
| 跨域控制 | iframe 模式支持配置允许的跨域域名 |

### 3.4 可维护性要求
| 要求 | 说明 |
|------|------|
| 代码规范 | 遵循 ESLint + TypeScript 规范 |
| 注释规范 | 关键逻辑添加英文注释 |
| 组件化 | 功能模块解耦，组件职责单一 |

## 4. 用户场景

### 4.1 场景一：Vue 项目集成
**用户角色**: Vue 3 项目开发者

**操作流程**:
1. 通过 npm 安装 chatbot 组件包
2. 在项目中引入并注册组件
3. 通过 props 传入配置参数
4. 监听组件事件回调

**预期结果**: 成功在项目中嵌入可用的 Chatbot 组件

### 4.2 场景二：传统网站集成
**用户角色**: 传统 Web 项目开发者

**操作流程**:
1. 部署 chatbot 独立 HTML 页面
2. 在宿主页面中通过 iframe 引入
3. 配置 iframe 参数和 postMessage 通信
4. 测试跨域消息传递

**预期结果**: 在非 Vue 项目中成功嵌入 Chatbot

### 4.3 场景三：移动端用户使用
**用户角色**: 终端用户 (移动设备)

**操作流程**:
1. 打开嵌入了 Chatbot 的网页
2. 点击右下角悬浮球
3. Chatbot 全屏展开
4. 输入文本或上传图片进行对话

**预期结果**: 移动端体验流畅，布局自适应

## 5. 约束与依赖

### 5.1 技术约束
- 必须使用 Vue 3 Composition API
- 必须使用 TypeScript
- UI 组件库使用 Element Plus

### 5.2 外部依赖
- SSE/WebSocket 接口 (流式输出)
- 图片上传接口
- 会话管理接口

### 5.3 开发约束
- 需提供模拟接口，无需依赖真实后端即可演示
- 代码需符合 Claude Code 生成规范
