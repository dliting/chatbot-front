## 1. 产品概述

### 1.1 产品定位
基于 Vue 3 + Element Plus 开发的可嵌入 AI 聊天机器人前端组件，支持悬浮球/侧边栏形态、响应式布局、多模态交互。

### 1.2 目标用户
- 需要在网站中集成 AI 对话功能的开发者
- 需要可定制化 Chatbot UI 的产品团队
- Vue 3 项目开发者（组件化嵌入）
- 非 Vue 项目开发者（iframe 嵌入）

### 1.3 核心价值
1. **开箱即用**: 无需复杂配置即可集成到现有项目
2. **响应式设计**: 自适配 PC/移动端不同屏幕尺寸
3. **多模态交互**: 支持文本、图片等多种输入方式
4. **灵活嵌入**: 支持 Vue 组件和 iframe 两种嵌入方式
5. **样式隔离**: 不污染宿主页面样式

## 2. 模式定义

本组件支持三种显示模式，每种模式适用于不同的使用场景。

### 2.1 扩展模式 (Extended Mode)

**模式标识**: `chatMode: 'extended'`

**描述**: 完整的桌面聊天界面，包含左侧会话列表和右侧聊天区域。

**适用场景**: 桌面端为主的全功能聊天应用。

**UI布局**:
```
┌─────────────────────────────────────┐
│  ┌──────────┐  ┌──────────────────┐ │
│  │会话列表  │  │   聊天区域        │ │
│  │          │  │                  │ │
│  │  新对话  │  │  消息列表        │ │
│  │  会话1   │  │                  │ │
│  │  会话2   │  │  [输入框]        │ │
│  │          │  │  [发送]          │ │
│  └──────────┘  └──────────────────┘ │
└─────────────────────────────────────┘
```

### 2.2 紧凑模式 (Compact Mode)

**模式标识**: `chatMode: 'compact'`

**描述**: 桌面端显示为侧边栏，移动端自动切换为全屏。

**适用场景**: 需要在不占用太多空间的情况下集成聊天功能。

**UI布局 (桌面)**:
```
┌─────────────────────────────────────┐
│ ┌──────┐  ┌──────────────────────┐ │
│ │聊天  │  │   主内容区域          │ │
│ │侧边栏│  │                      │ │
│ │      │  │                      │ │
│ └──────┘  └──────────────────────┘ │
└─────────────────────────────────────┘
```

**UI布局 (移动)**:
```
┌─────────────────────────────────────┐
│                                     │
│         全屏聊天界面                │
│                                     │
│  [消息列表]                         │
│                                     │
│  [输入框]                           │
└─────────────────────────────────────┘
```

### 2.3 悬浮模式 (Floating Mode)

**模式标识**: `chatMode: 'floating'`

**描述**: 页面右下角显示悬浮球，点击后打开可拖拽、可调整大小的聊天面板。

**适用场景**: 需要节省空间、按需访问聊天的场景。

**UI布局**:
```
页面右下角:
    ┌───┐
    │💬│  ← 悬浮球
    └───┘

点击后展开:
┌─────────────────┐
│  智能助手  [×]   │ ← 标题栏（可拖拽）
├─────────────────┤
│                 │
│  [消息列表]      │ ← 可调整大小
│                 │
│  [输入框]  [发送]│
└─────────────────┘
```
