# AI Chatbot UI 交互测试指南

## 概述

本指南基于产品需求文档（PRD）制定，涵盖所有核心功能、重要功能和扩展功能的UI交互测试。
**注意： 这类交互测试不仅仅是判断页面中某个ui元素是否存在，而是模拟人和浏览器交互操作来测试，使用“chrome-devtools” MCP来和浏览器交互来测试。**

## 测试环境

- **测试工具**: chrome-devtools MCP
- **测试入口**: http://localhost:5173/
- **测试浏览器**: Chrome (支持无头模式)
- **测试模式**: 所有示例页面需逐级测试

#### 4.4.1 8方向Resize详细验证

**北边 (North) - 顶部边缘**:
- 操作: 模拟 mousedown→mousemove(向上移动)→mouseup
- 验证: height 增加，y 位置减小（向上移动）

**南边 (South) - 底部边缘**:
- 操作: 模拟 mousedown→mousemove(向下移动)→mouseup
- 验证: height 增加，y 位置不变

**东边 (East) - 右侧边缘**:
- 操作: 模拟 mousedown→mousemove(向右移动)→mouseup
- 验证: width 增加，x 位置不变

**西边 (West) - 左侧边缘**:
- 操作: 模拟 mousedown→mousemove(向左移动)→mouseup
- 验证: width 增加，x 位置减小（向左移动）

**东北角 (Northeast) - 右上角**:
- 操作: 模拟 mousedown→mousemove(向右上方移动)→mouseup
- 验证: width 和 height 同时增加

**西北角 (Northwest) - 左上角**:
- 操作: 模拟 mousedown→mousemove(向左上方移动)→mouseup
- 验证: width 和 height 同时增加

**东南角 (Southeast) - 右下角**:
- 操作: 模拟 mousedown→mousemove(向右下方移动)→mouseup
- 验证: width 和 height 同时增加

**西南角 (Southwest) - 左下角**:
- 操作: 模拟 mousedown→mousemove(向左下方移动)→mouseup
