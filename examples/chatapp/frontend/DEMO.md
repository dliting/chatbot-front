# ChatApp 前端演示

本目录包含AIChat组件的三种交互模式演示。

## 路由架构

ChatApp 使用 Vue Router 4 进行单页应用路由：

```
Router (vue-router 4)
├── / (LandingPage) - 首页导航
│   ├── Extended Mode Card → /extended
│   ├── Sidebar Mode Card → /sidebar
│   └── Floating Mode Card → /floating
│
├── /extended (ExtendedDemo) - 扩展模式演示
├── /sidebar (SidebarDemo) - 边栏模式演示
└── /floating (FloatingDemo) - 悬浮模式演示
```

**路由配置文件**: `src/router/index.ts`

**路由特性**:
- HTML5 History 模式
- 懒加载组件 (使用 `() => import()`)
- 使用 `router.push()` 进行 SPA 导航

## 交互模式

### 扩展模式 (/extended)

**交互模式**: Extended
**内部布局**: Split (平铺)

全屏页面，左侧会话列表 + 右侧聊天区域

**布局示意**:
```
┌─────────────────────────────────────┐
│  ┌──────────┐  ┌──────────────────┐ │
│  │会话列表  │  │   聊天区域        │ │
│  │          │  │                  │ │
│  │  新对话  │  │  消息列表        │ │
│  │  会话1   │  │                  │ │
│  │  会话2   │  │  [输入框]        │ │
│  │          │  │  [发送]          │ │
│  └──────────┘  └──────────────────┘ │
└─────────────────────────────────────┘
```

**适用场景**:
- 独立的AI聊天应用
- 聊天机器人演示页面
- 专注于对话的体验页面

**组件**: `src/views/ExtendedDemo.vue`

### 边栏模式 (/sidebar)

**交互模式**: Sidebar
**内部布局**: Compact (紧凑)

桌面端: Tab切换视图，可切换会话列表/聊天视图
移动端: 自动切换为全屏模式

**布局示意**:
```
桌面端:
┌─────────────────────────────────────┐
│ ┌────────┐  ┌──────────────────────┐ │
│ │聊天    │  │   主内容区域          │ │
│ │边栏    │  │                      │ │
│ │        │  │                      │ │
│ │[会话|聊天]│  │                      │ │
│ └────────┘  └──────────────────────┘ │
└─────────────────────────────────────┘

移动端:
┌─────────────────────────────────────┐
│              全屏聊天界面            │
│  [← 返回]    [会话] [聊天]          │
│  ┌─────────────────────────────┐   │
│  │      消息列表                │   │
│  └─────────────────────────────┘   │
│  ┌─────────────────────────────┐   │
│  │ [输入框...]  [发送]          │   │
│  └─────────────────────────────┘   │
└─────────────────────────────────────┘
```

**适用场景**:
- SaaS后台管理系统
- 需要会话切换的场景
- 需要边栏形式的工具页面

**组件**: `src/views/SidebarDemo.vue`

### 悬浮模式 (/floating)

**交互模式**: Floating
**内部布局**: Compact (紧凑)

页面右下角显示悬浮球，点击后打开可拖拽、可调整大小的聊天面板

**布局示意**:
```
页面右下角 (收起状态):
    ┌───┐
    │💬│  ← 悬浮球 (可拖拽)
    └───┘

点击后展开:
┌─────────────────────┐
│  智能助手    [×]     │ ← 标题栏 (可拖拽)
├─────────────────────┤
│                     │
│    [消息列表]       │ ← 内容区域 (可调整大小)
│                     │
├─────────────────────┤
│ [输入框...]    [发送]│
└─────────────────────┘
```

**适用场景**:
- 营销落地页
- 文档/帮助页面
- 不希望聊天干扰主内容的场景

**组件**: `src/views/FloatingDemo.vue`

## 配置选项

### 新版配置（推荐）

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `mode` | `'extended' \| 'sidebar' \| 'floating'` | `'floating'` | 交互模式 |
| `layout` | `'split' \| 'compact'` | 根据mode自动 | 布局形式 |
| `apiBaseUrl` | `string` | - | API基础URL |
| `enableImageUpload` | `boolean` | `true` | 启用图片上传 |
| `enableSessionManager` | `boolean` | `true` | 启用会话管理 |
| `maxImageCount` | `number` | `4` | 最大图片数量 |
| `position` | `string` | `'bottom-right'` | 悬浮球位置 |
| `panelWidth` | `number` | `400` | 面板宽度(px) |

### 旧版配置（兼容）

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `chatMode` | `'extended' \| 'compact' \| 'floating'` | `'floating'` | 聊天模式（旧版） |

## 本地开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 环境变量

创建 `.env` 文件:

```bash
# Mock模式（默认）
VITE_API_BASE_URL=http://localhost:3001

# Real模式（需要Ollama）
VITE_API_BASE_URL=http://localhost:3000
```
