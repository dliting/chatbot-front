# ChatApp Frontend

ChatApp 前端示例应用,展示 AIChat 组件的多种使用模式。

## 演示模式

本项目包含以下演示模式:

- **紧凑模式** - 侧边栏布局,适合后台管理系统
- **扩展模式** - 全屏聊天界面,适合独立应用
- **悬浮模式** - 悬浮球按钮,适合营销页面
- **Iframe嵌入** - 跨域嵌入,支持postMessage通信

详细文档请参阅 [DEMO.md](./DEMO.md)。

## 快速开始

```bash
npm install
npm run dev
```

## 开发

- Vue 3 + TypeScript
- Vite 构建工具
- Vue Router 路由管理
